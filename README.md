# 🔬 Research Paper Analyzer

An AI-powered web application that analyzes research papers and extracts important information such as the **problem statement, methodology, algorithms, dataset, results, limitations, research gap, and future work**.

The application uses **Google Gemini, LangChain, Pydantic, and Streamlit** to convert unstructured research paper text into structured information.

## 🚀 Live Demo

👉 [Research Paper Analyzer](https://researchpaperanalyzer-etc6g2ngwk3fskt22rddqe.streamlit.app/)

## 📌 Features

- 📄 Analyze research paper text
- 🧠 AI-powered analysis using Google Gemini
- 🔍 Extract important research information
- 📊 Structured output using Pydantic
- 🔗 LangChain-based prompt processing
- 🌐 Interactive Streamlit interface
- ☁️ Deployed on Streamlit Community Cloud

## 🧾 Information Extracted

The application extracts:

- **Title**
- **Authors**
- **Problem Statement**
- **Methodology**
- **Algorithms**
- **Dataset**
- **Results**
- **Limitations**
- **Research Gap**
- **Future Work**
